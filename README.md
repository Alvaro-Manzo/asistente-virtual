### 🚀 **Instalación Rápida (macOS)**

```bash
# 1. Clonar/descargar el proyecto
# 2. Dar permisos y ejecutar instalación automática
chmod +x install.sh run.sh
./install.sh

# 3. Ejecutar el asistente
./run.sh
```

### 📋 **Instalación Manual**

```bash
# Crear entorno virtual
python3 -m venv .venv
source .venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt

# Ejecutar
python main.py
```

## 🔧 **Solución de Problemas**

### **Error de Voz:**
- ✅ **Automático**: Cambia a modo texto
- ✅ **Respaldo**: Comando `say` de macOS
- ✅ **Manual**: Selecciona modo texto (opción 2)

### **Error de Micrófono:**
- ✅ **Automático**: Modo texto como respaldo
- ✅ **Dependencias**: Instalación automatizada de PyAudio

### **Error de Dependencias:**
- ✅ **Verificación automática** al inicio
- ✅ **Script de instalación** incluido
- ✅ **Entorno virtual** aislado
